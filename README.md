# analyst-skills

一套**分析师系列 skill**的方法论与骨架——把"做严谨、可追溯的分析"这件事工程化。

每个分析师是一个独立 skill，共享同一套方法论"操作系统"（`shared/`），各自有专属框架与工作流（`skills/`）。

## 矩阵

| Skill | 角色 | 核心问题 |
|---|---|---|
| **analyst-tech** | 中立技术真相判断者 | 这技术是不是真的 / 有多成熟？ |
| **analyst-people** | 还原一个人的审美 | 这个人怎么想 / 怎么走来的 / 走向哪？ |
| **analyst-business** | 卖买双视角拆商业模式 | 这门生意怎么赚钱 / 值不值这个价？ |
| analyst-media | 媒体视角评估（planned） | 这是不是好故事 / 怎么讲？ |

## 共享方法论（`shared/methodology/`）

- **四大铁律**：先选框架 / 关键事实三源验证 / 每个结论标信心等级 / 信息缺口透明
- **五种核心能力**：信息追溯 / 第一性原理 / 纵向 / 横向 / 历史时间轴
- **Plain-Speak**：大白话 + 专业版双层表达
- **事实穷尽优先于推理**：事实层穷尽到 bar 才能进推理层
- **买方/卖方双视角**：所有对外材料是卖方产物，分析师永远切到买方验，差额即本质

## 结构

```
shared/        方法论 / 通用框架 / 信源分级 / 模板 / 工作流骨架
skills/        各分析师专属 SKILL.md + workflow.md + 专属框架 + 模板
```

> **说明**：本仓库只公开**方法论与 skill 文本**。具体的分析产出（对真实对象的 dogfood / 研究记录）不包含在内。
