# 第一性原理反例案例库

**用途**：每次第一性 sanity check 时，主动调 1-2 个同型反例做对照，避免对第一性原理的过度自信。

**使用规则**：
- 我说"X 不可能" → 查"看起来不可能但发生了"的同型案例
- 我说"X 一定成立" → 查"看起来一定但失败"的同型案例
- **反例不是"破除一切"**，是校准信心。绝大多数时候第一性还是对的。反例的作用是给结论加概率区间，不是动摇结论。

---

## 类别 A：看起来违反第一性，但事实成立

这些是"专家曾经说不可能" 但发生了的案例——提示我们对未来"X 不可能"的判断保持谦逊。

### A.1 EUV 光刻让 3nm 量产
- **当时共识**（2010s 早期）：5nm 以下因光刻分辨率和良率问题不可能商用
- **实际发生**：ASML 用 13.5nm EUV + 多重曝光 + 计算光刻，TSMC 2022 年 3nm 量产
- **教训**：制造工艺的"物理极限" 往往不是绝对极限，是当前工程方案的极限
- **适用同型**：所有"X 工艺到了物理极限" 的判断都要查这个反例

### A.2 TSMC 从落后到超越 Intel 制程
- **当时共识**（2010 年前）：Intel 在制程上领先全球 2-3 年，台积电是 fast follower
- **实际发生**：Intel 在 10nm 反复延期（2017-2021），TSMC 用 7-8 年从落后追到超越，并在 5nm/3nm 领先
- **教训**：领跑者的"二十年护城河" 可以在 5-10 年内瓦解，前提是后发者专注 + 领跑者战略失误
- **适用同型**：所有"AMD 二十年追不上 NVIDIA 所以海光也追不上" 类比 — 必查此反例

### A.3 SpaceX 可回收火箭
- **当时共识**（2000s）：火箭一级回收"经济上不可行，技术上太复杂"
- **实际发生**：2015 年首次成功，2020s 后已成行业标准
- **教训**：把"我们没做过" 当"做不到" 是常见认知谬误
- **适用同型**：所有"业内三十年没人做成" 类判断

### A.4 Transformer 击败 RNN/LSTM（然后被 SSM/Mamba 局部挑战）
- **当时共识**（2017 前）：序列建模 RNN/LSTM 是标准，attention 只是辅助
- **实际发生**：2017 "Attention is all you need" → 5 年内统治 NLP
- **二次反转**：2023 起 Mamba/SSM 在长序列上局部击败 Transformer — 提示霸主也会被颠覆
- **教训**：架构主导期 5-10 年是常态，不是终态
- **适用同型**：任何"XX 架构已成定局" 类断言

### A.5 中国电动车从落后到全球第一
- **当时共识**（2015 前）：传统燃油车技术中国落后德/日 20-30 年
- **实际发生**：通过押注电动化绕过内燃机护城河，2024 比亚迪销量超特斯拉成全球最大 EV 厂商
- **教训**：换赛道是后发追赶最有效的方式（不是在原赛道死磕）
- **适用同型**：所有"中国在 XX 领域追不上" 判断 — 问：是否存在换赛道的可能？

### A.6 DeepSeek 用 ~$6M 训练对标 GPT-4 的模型
- **当时共识**（2023）：训练前沿模型 = 至少 $100M+ + 数万张 H100
- **实际发生**：2024.12 DeepSeek V3 用约 2048 张 H800、~$6M 成本，benchmark 接近 GPT-4
- **教训**：算法 + 工程优化能 10-100× 压缩训练成本，"必须烧钱" 假设有边界
- **适用同型**："必须巨额投入" 类断言

## 类别 B：看起来合理，但其实违反第一性

这些是"听起来很对"但**违反基本约束**的主张——提示我们警惕"叙事完美 = 真相"的陷阱。

### B.1 永动机的各种伪装
- **形态**：从机械永动机到"零点能"到"无限免费能源" — 总有人在包装
- **违反**：热力学第二定律
- **教训**：任何号称"打破能量守恒" 的方案 = 必假，0 例外
- **适用同型**：所有"无中生有"叙事

### B.2 "摩尔定律永远持续"
- **共识**（1990s-2010s）：晶体管数每 18-24 月翻倍是永恒规律
- **违反**：物理上晶体管尺寸有量子隧穿下限（< 2nm 后效应显著）；经济上单位面积成本随节点缩小指数上升（dennard scaling 已死）
- **实际发生**：2010s 起摩尔定律事实上放缓；改用 chiplet / 3D 堆叠延续
- **教训**：把经验外推当物理定律，是经典错误
- **适用同型**：任何"指数增长永远持续" 类预测

### B.3 "人脑 ≈ LLM 参数对应"过度类比
- **形态**：人脑 100T 突触 ≈ 100T 参数 LLM → 所以更大模型 = 接近 AGI
- **违反**：神经元和参数不是同型（神经元有动态可塑性、化学信号、时间编码、能耗 10^4 倍低于 GPU）；类比在量级和机制上都不成立
- **教训**：跨学科类比要严格检验同型性，不是数字大小匹配就成立
- **适用同型**：所有"X 数字接近人体某指标所以接近人体能力" 类断言

### B.4 "中国市场 = 14 亿人 × $X = 万亿市场"
- **形态**：互联网/SaaS/医疗等领域的"潜在市场" 经典 PPT
- **违反**：实际购买力分布极不均（top 10% 占 70% 消费）；许多产品的实际可达人群是 1-2 亿；支付意愿差异 5-10×
- **教训**：自上而下市场规模拍脑袋 = 几乎一定高估 3-10×
- **适用同型**：所有"X 是万亿赛道" 类宣称 — 必查自下而上验证

### B.5 "AI 让一切重做一遍"
- **形态**：每个 SaaS / 工具类品类都要 "AI 重做"
- **违反**：很多行业的瓶颈是**销售渠道 / 监管准入 / 客户数据所有权**，不是产品智能化
- **教训**：技术解锁不等于市场重洗；存量护城河（渠道 / 客户关系）常常更重要
- **适用同型**：所有"AI native 必然颠覆传统" 类判断

### B.6 "区块链解决一切信任问题"
- **形态**（2017-2022）：从 DeFi 到供应链到身份认证，都"应该上链"
- **违反**：99% 的实际信任问题不是密码学问题，是法律 / 制度 / 现实世界数据可信度问题；链上数据被链下信任锚定
- **教训**：技术解决方案要匹配真实问题约束，不是"看起来能"就能用
- **适用同型**：所有"用 XX 新技术解决 YY 经典问题" 类断言

## 怎么用这个库

### Step 4 第一性 sanity check 流程

1. 做完第一性推理，得到结论 X
2. 翻这个库，找 1-2 个"同型反例"
3. 对照思考：
   - 我的判断更像 A 类（被反例打脸）还是 B 类（被反例确认）？
   - 反例和我的情况的关键差异是什么？
4. 据此调整信心等级 / 加上"如果……则……"边界条件

### 累加规则

每次任务遇到值得收录的新反例（无论 A 类还是 B 类），在文件末尾累加一条。格式：
```
### A.X / B.X [标题]
- 当时共识 / 形态：
- 违反 / 实际发生：
- 教训：
- 适用同型：
```

**保持简洁**：每条 4-6 行，不展开成长文。库的价值在覆盖广度，不在单条深度。
