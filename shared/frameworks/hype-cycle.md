# Gartner Hype Cycle（技术成熟度曲线）

判断一项技术处在炒作周期的哪一阶段。中立的"集体认知阶段" 判断工具。

## 五个阶段

```
        Peak of Inflated
        Expectations
            /\
           /  \
          /    \____
   Innovation    Trough of
   Trigger      Disillusionment   Slope of      Plateau of
      |                  \      Enlightenment  Productivity
      |                   \____/_____________/
______|_____________________________________________________
                          时间 →
```

| 阶段 | 客观特征（技术分析师视角） |
|---|---|
| **创新触发期** | 学术突破、首个 demo、可行性问题尚未解决 |
| **期望膨胀峰** | 媒体狂欢，承诺远超能力，估值与基本面脱钩 |
| **幻灭低谷** | 失败案例集中爆出，关注度暴跌，真技术在此沉淀 |
| **启蒙爬坡** | 真实用例出现，商业模式跑通迹象，winner 浮现 |
| **生产高原** | 主流采用，技术演化趋稳，进入维持期 |

## 判断当前阶段的 5 个信号

### 信号 1：媒体热度曲线
- 用 Google Trends / 百度指数 / 微信指数看 12-24 个月趋势
- 在峰值时 = 期望膨胀峰；在低谷且仍有讨论 = 启蒙爬坡前期

### 信号 2：融资数据
- 该赛道融资额、轮次密度（CB Insights / IT 桔子 / Crunchbase）
- 总融资额骤增 + 估值跳涨 = 接近峰值
- 融资轮次延长（A 轮拖 18 个月）+ 估值持平 = 幻灭低谷

### 信号 3：关键玩家声明
- 大厂战略发布会的提及频率（CES、Apple WWDC、Google I/O 等）
- 大厂从"All in" 转向"务实落地" = 幻灭低谷过渡到启蒙

### 信号 4：技术指标 vs 商业指标
- 期望峰期：技术指标霸屏（benchmark、参数量、accuracy）
- 启蒙期：商业指标登场（LTV、CAC、留存、复购）

### 信号 5：人才流动
- 进入期：顶尖人才单向流入
- 峰值过后：明星创业者出走、连续创业者重返大厂
- 启蒙期：跨界人才加入（产品、销售、行业老兵）

## Handoff 提示库（供下游合作者参考）

下面两张表是**你在判断完技术处于哪个阶段后，可以提供给下游合作者的提示**。技术分析师**不下结论**，但给参考。

### → 投资合作者（analyst-business）的参考提示

| 阶段 | 投资视角的典型动作 |
|---|---|
| 创新触发期 | 早期布局窗口，押注"赛道+人"；估值便宜但风险极高 |
| 期望膨胀峰 | 估值与基本面脱钩，警惕；除非有信息差，否则不出手 |
| 幻灭低谷 | 一般被视为最优入场窗口：真技术在此沉淀，估值回归 |
| 启蒙爬坡 | 中后期适配，回报倍数缩窄但确定性高 |
| 生产高原 | 接近 PE 估值，VC 通常不再适配 |

**例外**：基础设施类技术（如云计算、数据库）跨越 10+ 年，子赛道位置才是关键。

### → 媒体合作者（analyst-media）的参考提示

| 阶段 | 媒体角度的典型切入 |
|---|---|
| 创新触发期 | "下一个 XX 浪潮：是什么" 教育类 |
| 期望膨胀峰 | "ZZ 已经被高估了" 反共识、戳泡沫 |
| 幻灭低谷 | "为什么 YY 没能成功" 复盘类，捕捉"真 winner" |
| 启蒙爬坡 | "XX 公司是如何二次崛起的" 趋势确认类 |
| 生产高原 | "XX 已成基础设施" 产业地图类 |

## 应用示例

> **题目**：判断 LLM 应用层（agent / copilot 类产品）目前处于 Hype Cycle 哪个阶段（截至 2026 Q1）

| 信号 | 观察 | 指向阶段 |
|---|---|---|
| 媒体热度 | 较 2024 峰值下降约 40%，但仍高位 | 峰值之后、低谷之前 |
| 融资数据 | 2025 全年融资额下降，估值倍数收窄 | 进入低谷过渡 |
| 大厂态度 | 从"All in agent" 转向"垂直场景务实落地" | 同上 |
| 技术 vs 商业指标 | 媒体开始报道 ARR、留存、毛利率 | 启蒙爬坡前期 |
| 人才流动 | 部分明星离开、行业老兵进入 | 同上 |

**技术分析师的判断**：LLM 应用层正处于「幻灭低谷过渡到启蒙爬坡」阶段。**信心：中**（基于宏观信号，未做具体子赛道拆分）。

**Handoff Hints**（基于上述判断）：
- **→ 投资合作者**：从阶段看，这一时段历史上常为 A/B 轮较优入场窗口；但子赛道分化大，建议拆到"垂直 agent / 通用 agent / 工具链"分别看 winner 信号
- **→ 媒体合作者**：适合"幸存者复盘"与"真实商业模式" 类选题；阶段过渡期是反共识表达的好时机

## 用这个框架时常见的错误

1. **把不同子赛道混为一谈**。"AI" 整体没意义，要拆到"LLM 基础模型 / 应用层 / 垂直行业模型"等粒度。
2. **静态判断**。曲线是动态的，要预测下一个 12 个月走向哪。
3. **只看英文世界信号**。中国市场的 Hype Cycle 阶段往往与美国错开 6-18 个月。
4. **忘记 Hype Cycle 是描述性而非预测性的工具**。它告诉你"目前像什么阶段"，不直接告诉你"未来会发生什么"。要结合 S-Curve 等框架做预测。
