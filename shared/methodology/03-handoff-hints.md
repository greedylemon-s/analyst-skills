# Handoff Hints — 三人协作规范

分析师团队由 **analyst-tech / analyst-business / analyst-media** 三人组成。每个 skill 都不替别人下结论，但会给别人"指方向"。

---

## 核心原则

每份输出必须以 **Handoff Hints** 收尾。

- **指方向，不下结论**——写"投资视角下重点看 X、Y、Z"，**不**写"建议投" / "建议写"
- **3-5 条要点即可**，不需要长篇
- **越界 = 角色不清晰 = 输出可信度下降**

---

## 三个分析师之间的协作方向

```
analyst-tech （技术真相）
    ↓ hints
analyst-business   （估值/护城河/退出）
analyst-media（叙事/时机/独家性）
```

analyst-tech 是"基座"——每次输出都附两块 hints，给 vc 和 media。
analyst-business 和 analyst-media 接收 tech 的 hints 作为输入，自己再产出投资 / 媒体视角的判断。

未来可能扩展双向 hints（vc 反向告诉 tech "我做投资判断时还需要哪些技术细节"），但 v1 阶段单向即可。

---

## Hints 块模板

### 给投资合作者的提示（→ analyst-business）

围绕你的判断，提示投资视角下值得重点关注的事项（3-5 条）：

- **估值锚点**：当前阶段对应市场上类似阶段的估值水平有什么参考
- **关键护城河信号 / 红旗**：从判断中能看出的真壁垒 vs 包装话术
- **DD 优先级**：如果要进一步投资尽调，最该优先验证的 2-3 件事
- **时机判断**：建议进场窗口或观察期
- **结构性风险**：可能让投资判断失效的关键不确定性

**注意**：你**不出**投资决策结论。你只指方向。

---

### 给媒体合作者的提示（→ analyst-media）

围绕你的判断，提示媒体视角下值得重点关注的事项（3-5 条）：

- **故事价值**：判断中是否含有可被读者理解、有冲突或反共识的元素
- **叙事角度**：有 2-3 个值得展开的叙事切入点
- **时机窗口**：什么时间发布最有价值（早 / 同步 / 复盘）
- **独家性 / 信源**：哪些细节是公开报道少见的，可作为深度报道的差异化
- **延伸选题**：本次分析顺延出的、值得未来跟踪的相关选题

**注意**：你**不出**编辑决策结论。你只指方向。

---

## 与用户协作的衔接

- 用户不需要每次说明"这次是用于投资还是媒体"——两块 hints 让他自取所需
- 如果用户主动说明只用于其中一种，可以在对应 hints 块略加侧重；但分析本体保持中立
