# 铁律 5 — 事实穷尽优先于推理

**作用范围**：全部 analyst-* skill
**首次浮现**：人物分析 dogfood
**ADR**：（人物分析师起手时确立）

## 规则

> 在做任何推理（动机、心路历程、思维模式、未来预测）之前，必须先把"事实层"穷尽到约定 bar：
> - **说过什么**（言论库）
> - **做过什么**（事件库）
> - **这些事的价值/权重**（事件评估）
>
> 推理必须站在事实库之上，**不能跳过**。

## 为什么

分析工作有一个常见陷阱：**拿到几条线索就开始脑补**。
- 信息不足时的推理会被仅有几条信息**锚定**（anchoring bias）
- 选择性引用——只用支持自己叙事的事实
- **事后归因**——把已知结果合理化为必然因果（hindsight bias）

事实穷尽优先于推理 = 对抗这类陷阱的工程化纪律。

## 落地

### 阶段化工作流

所有 analyst-* skill 的工作流必须包含明确的"事实层 phase"，**禁止与"推理层 phase"并行**：

| skill | 事实层 phase | 推理层 phase |
|---|---|---|
| analyst-people | Phase 1 言论库 + 事件库 | Phase 2 痕迹 + 画像 |
| analyst-tech | Step 1-3 信源 + 一手数据 | Step 4-5 框架 + 判断 |
| analyst-business | Phase 0-1 卖方 pitch 复原 + 三表/交易层取证 + 客户证据 | Phase 2 买方逐 thread 剥茧 → 估值裁决 |
| analyst-media | （待 media 起手时定义） | — |

### bar 检查

事实层 phase 必须达到预设 bar 才能进推理层。bar 由用户在启动前与 skill 一起敲定。

### "ROI 优先于完整性"的边界

本铁律**不是**"必须穷尽到 100%"。bar 是工程化目标。达不到 bar 的部分要：
- 标记为"已识别缺口"
- 评估是否触发 M-xxx 手动接力
- 如接力也不行 → 明确"在此缺口下不做推理"

不能用"已穷尽到 bar"作为"剩下都可以推断"的通行证 — 缺口范围内的判断仍要标注"信心低 / 推断"。

## 反例（违反铁律 5 的脑补）

❌ "他这么聪明，肯定是名校毕业" — 没有"教育背景"事实就推断
❌ "他离开红杉是因为对沈南鹏不满" — 没有冲突事实就推断动机
❌ "这家公司一定会成为下一个 Google" — 没有量化锚就预测未来
❌ "他喜欢艺术 / 性格内向" — 没有审美 / 行为证据就贴标签

## 正例

✅ 先 fetch 36 氪 PitchHub 拿到 100% 持股数据 → 再推断"创始人主导型组织"
✅ 先收集 40+ 言论 → 找出反复出现的"组织能力"主题 → 推断"组织作为第一性变量"
✅ 先 Phase 0 信源勘探 → 再决定 Phase 1 主战场

## 与其他铁律的关系

- 铁律 2（信源三角验证）：保证事实层每个条目的可靠性
- 铁律 3（信心标注）：让推理层基于事实层的扎实度评级
- 铁律 4（信息缺口透明）：让事实层达不到 bar 的部分诚实暴露
- **铁律 5（本条）**：定义事实层与推理层的**先后顺序**，保证以上三条不会被绕过

- 全程禁止 Phase 1 未到 bar 就跳到推理
