# Plain-Speak 双层表达原则

**输出层铁律**。所有 analyst-* skill 通用。

技术 / 金融 / 行业分析不是"用更复杂的词包装显得专业"。
**Feynman 标准**：讲不清楚就是没真懂。

---

## 双层表达模式

每个核心概念在首次出现时，必须双层呈现：

```
用大白话说：[一两句话的小学生版本，可用类比、生活例子]
专业上：[严谨技术 / 金融 / 行业表达]
```

### 例（合格 vs 不合格）

❌ 单层（不合格）：
> "LLM 训练在第一性原理上等价于最小化交叉熵 = KL 散度"

✅ 双层（合格）：
> 用大白话说：训练 LLM 就是让它"猜下一个字时尽量不惊讶"。模型猜对得越多、越准确，"惊讶程度" 就越低，能力就越强。
>
> 技术上：训练目标是最小化模型预测分布与真实分布之间的交叉熵；这与 KL 散度在数学上等价。

---

## 规则

- **首次出现必带 plain-speak**。第二次再出现可以直接用术语
- **类比优先于定义**。"猜下一个字" 比"自回归生成" 更好懂
- **避免 jargon 堆叠**。一句话里出现 ≥3 个未解释术语 = 黄牌
- **不是降低严谨性**——大白话**后面**仍要给专业准确版。两层并存

---

## 为什么这条铁律

- 用户的工作场景跨越投资圈与媒体圈，**都需要把专业真相翻译给非工程师听众**
- 如果分析师只会说"业内说法"，本质上是在抄信源，没在做翻译
- Feynman 自检：你写完一段，给一个外行朋友看，他能不能 30 秒说出"这在讨论什么"？不能 → 重写

---

## 不合格输出的五种症状

1. **罗列型**：堆叠事实，没有判断、没有第一性、没有类比
2. **脑补型**：缺信源处用"通常""一般""业内估计" 填充
3. **过度自信型**：未知清单为空，但其实有很多没确定的事
4. **术语墙型**：满篇 jargon 堆叠，缺少 Plain-Speak 双层表达 ← **本文件重点**
5. **静态切片型**：只描述"当前现状"，没有"如何走到当下" 的时间轴

合格输出的 5 个特征：**有判断 / 有边界（明示未知）/ 有思考层次 / 能被外行听懂 / 有动力学视角**。
