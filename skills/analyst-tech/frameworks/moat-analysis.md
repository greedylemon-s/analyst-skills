# 7 Powers：技术企业的护城河分析

来自 Hamilton Helmer《7 Powers》。判断"一家公司能不能持续赚到超额利润"的最严谨框架之一，源于战略与投资分析，但用于任何严肃的"护城河强度"判断都适用。

## 7 种力量

每种 Power 同时满足两个条件才成立：
1. **Benefit**：拥有它的公司能获取超额利润
2. **Barrier**：竞争对手无法（或不愿）复制它

| Power | 核心机制 | 技术领域典型表现 |
|---|---|---|
| **Scale Economies** | 规模越大，单位成本越低 | 云计算、晶圆代工、大模型训练 |
| **Network Economies** | 用户越多，产品对每个用户越有价值 | 平台型 SaaS、开发者生态、社交网络 |
| **Counter-Positioning** | 新位置让在位者无法复制（复制即自伤） | 颠覆式定价（freemium）、技术路径切换 |
| **Switching Costs** | 用户更换供应商代价过高 | 企业 SaaS、ERP、底层基础设施 |
| **Branding** | 心智溢价（仅消费品/部分 B2B 适用） | Nvidia 之于 GPU、Apple 之于消费电子 |
| **Cornered Resource** | 独占某稀缺资源 | 关键专利、稀缺数据集、独家供应、关键人物 |
| **Process Power** | 流程优势难以模仿（需多年积累） | 台积电先进制程、SpaceX 制造工艺 |

## 应用流程

### Step 1：识别候选 Power

逐项排查 7 种 Power。对每一种问：
- 这家公司有这种 Power 吗？
- 证据是什么？
- Benefit 和 Barrier 都满足吗？

### Step 2：判断 Power 的强度

每种 Power 可分为三档：
- **强**：竞争对手在可见的 3-5 年内无法复制
- **中**：可被复制但需付出显著代价
- **弱/无**：可被快速复制

### Step 3：识别 Power 的"演化阶段"

Power 是动态的。新公司通常先获得一种 Power，再"加固/叠加"出多种。演化经验：
- 早期：1 种主要 Power 即可
- 成长期：开始叠加第 2-3 种
- 成熟期：3+ 种 Power 协同

## 技术公司 7 Powers 的特别检视

### Scale Economies 的真假判断

**真规模效应**：
- 大模型公司：训练成本固定后边际推理成本递减
- 云厂：基础设施利用率随规模上升

**假规模效应**：
- "AI 应用"：每个 API 调用都付费给基础模型，无规模效应
- 定制化 B2B：每个客户都需要单独工程团队

### Network Economies 的边界

不是所有"用户增长"都构成网络效应。要问：
- 第 100 万个用户的加入，**对前 99.99 万用户有什么具体价值增加**？
- 如果答案是"广告位多了"，那是平台效应不是网络效应

### Cornered Resource 在 AI 时代的新变形

传统理解：稀缺专利、矿权、独家代理
AI 时代新变形：
- **独家数据**：医院真实病例数据、企业内部对话数据
- **独家算力**：与 Nvidia / 台积电的优先供应关系
- **独家人才网络**：能挖到 Top 50 大模型研究员的能力

### Process Power 在硬科技中的判断

判断标准：
- 该流程是否需要 5+ 年才能从 0 复刻？
- 是否有大量 tacit knowledge（无法文档化）？
- 离职员工能否带走？（不能 = 真 Process Power）

## 反向检视：常被误判为护城河的"假壁垒"

| 看似护城河，其实不是 | 为什么 |
|---|---|
| "我们的算法很先进" | 算法是论文，论文可复现 |
| "我们的模型参数最大" | 钱能解决的问题不是壁垒 |
| "我们 GMV/ARR 增长最快" | 是结果不是原因，要问"为什么是你" |
| "我们的团队是 Google/OpenAI 出来的" | 团队会跳槽，知识会扩散 |
| "我们有专利" | 多数专利的实际可执行性很弱，要做 FTO 分析 |
| "我们的产品体验更好" | UI/UX 可复制，要问"为什么对手无法复制" |

## 用这个框架时常见的错误

1. **混淆"Operational Excellence" 与"Power"**。执行得好不等于有壁垒。Power 必须能阻止竞争对手。
2. **只看当下，不看演化**。早期没有 Power 的公司，可能在某个拐点突然形成 Power（如 Tesla 的电池工艺）。要问"什么事件会让 Power 出现/消失"。
3. **过度关注创始人魅力**。创始人是资源不是 Power（除非该资源能持续产生稀缺供给）。
