# Workflow — analyst-people

> 4 阶段流程。每个 phase 有独立产物 + bar + 自检。可暂停 review 再继续。
> 首次完整范例：人物分析 dogfood（范例存本地，未公开）

## 启动前对齐 3 件事

| # | 决定 | 默认 |
|---|---|---|
| 1 | bar 档位（轻量 / 标准 / 深挖） | 标准 |
| 2 | 付费阈值 | 0（全零付费） |
| 3 | 工作目录 | `~/analyst-skills/runs/<对象-slug>/` |

### bar 三档定义

| 档位 | 一手言论 | 关键事件 | 独立信源 | 适用 |
|---|---|---|---|---|
| 轻量 | ≥10 | ≥10 | ≥3 | 初探 / 不确定值不值得深挖 |
| **标准** ⭐ | **≥40** | **≥25** | **≥5 + 一/二手分层** | 出画像 |
| 深挖 | ≥100（跨 5 年） | ≥50 | ≥8 + 演变追踪 | 长报告 / 长期跟踪 |

## Phase 0 信源勘探 (Source Map)

**目的**：抓任何"内容"之前，先把"去哪抓"摸清楚。

**步骤**：
1. **身份基线 fetch 核实**（按"模型记忆必须 fetch 核实"铁律 — 不直接信记忆）
2. **罗列全部公开发声渠道**
   - 自有阵地（官网 / Newsletter / Substack）
   - 长文（公众号 / Medium / 博客）
   - 长音视频（播客 / YouTube / B 站 / 演讲）
   - 短文（X / 即刻 / 微博 / 知乎 / LinkedIn）
   - 体系化外部访谈（与媒体的长期合作）
   - 二手深度报道
   - 数据库 / 工商
3. **评估每个渠道**：可抓性 × 信息密度
4. **标记必然要 M-xxx 接力的缺口**
5. **识别"缺位信号"**（不存在本身就是审美痕迹）

**产物**：`step-0-source-map.md`
- §1 身份基线（含模型记忆修正记录）
- §2 信源全景图（按类别）
- §3 优先级矩阵
- §4 M-xxx 接力候选清单
- §5 关键"缺位信号"
- §6 已识别的审美预热（Phase 1 待深挖的种子）
- §7 自检（按"完善"硬定义）

**"完善"的硬定义**：
| 标准 | 含义 |
|---|---|
| 入口穷尽 | 全部公开发声渠道列出（含抓不到的） |
| 可抓的全抓 | 每个能抓的渠道，抓到目前工具能拿到的全部 |
| 抓不到的标记 | 写明原因 + 缺口大小估计 |
| 二次核验 | 关键事实至少两个独立信源 |

→ "完善" ≠ "全抓到"。**全部入口被映射、缺口被诚实标记** = 完善。

## Phase 1 言论库 + 事件库 + 价值评估（事实层）

**铁律 1 强制**：本 phase 必须达到 bar 才能进 Phase 2。

### 1.1 言论库 quotes.md

字段：`id | date | source | firsthand | topic | quote | aesthetic_hint`

- `firsthand`: ✅ 本人原话 / 🟡 转述或合作署名 / 🔴 第三方描述
- `aesthetic_hint`: 这条对应的审美线索（待 Phase 2A 落到具体痕迹 ID）

**结构**：按时间分 section（早期 → 中期 → 当前），便于看演变。
末尾附"缺失"section（已识别需补的言论缺口）。

### 1.2 事件库 events.md

字段：`id | date | title | type | source | confidence | weight | related_quotes`

- `confidence`: ✅ 一手自述 / 🟢 两源以上 / 🟡 单源未交叉 / 🔴 推断
- `weight`: ⭐⭐⭐ 转折级 / ⭐⭐ 关键级 / ⭐ 一般

**结构**：按人生阶段分 section（教育 / 早期职业 / 创业期 / 各战略转向期）。
末尾附：
- 业务规模事实
- 关系网络
- 事件价值评估总览（按 weight × 时间排）

### 1.3 事件价值评估（不是动机推理）

对每个事件评估**事实层的权重**，**不评估动机**：
- 影响圈：影响多少人 / 多大范围
- 转折性：是不是改变了后续轨迹的事
- 时长占比：在这件事上反复回归 / 投入多久
- 独特性：多大程度上是"只有他做"的
- 自我提及频率：他公开 / 私下反复提起的次数

→ 反映在 events.md 的 `weight` 字段。

**自检 bar**（标准档）：
- 一手言论 ≥40 ✅
- 关键事件 ≥25 ✅
- 独立信源 ≥5 ✅
- 一/二手分层 ✅

## Phase 2A 抽审美痕迹

**目的**：把事实层翻译成审美痕迹——5 种类型，每条对应 Q-xxx / E-xxx 证据 ID。

### 5 种痕迹

| 痕迹 | ID 前缀 | 怎么找 |
|---|---|---|
| 选择 | S-x | portfolio / 作品列表 / 砍掉的产品 / 拒过的合作 |
| 评价 | V-x | 反复推荐 / 反复批评的对象 |
| 模仿 | M-x | 偶像系谱、自我比拟、引用频次、致敬对象 |
| 不可妥协 | NC-x | 拒过的钱、砍掉的产品、坚持的标准 |
| 演变 | EV-x | 时间切片对比 + 触发事件 |

### 产物：`aesthetic-traces.md`

- §1-5 五种痕迹（每条 ID 化 + 证据 + 信心等级）
- §6 综合：审美核心陈述 ≤ 5 条（每条对应证据 ID 列表）
- §7 当前未被覆盖的审美维度（缺口）
- §8 自检

### 6 条综合陈述的格式

每条遵循：**"什么样的 X 是好 / 不好"** + 证据 ID 列表

例（格式示意）：
> **A-1 美学第一性 — 什么是好的判断**
> <什么样的判断是"好"> = 真问题；<什么是噪音> = 噪音。
> 证据：<V-x / S-x / EV-x 列表>

**自检 bar**：
- 每条 claim 都有证据 ID ✅
- 信心等级标注 ✅
- 缺口诚实标注 ✅

## Phase 2B 推导四画像

**目的**：基于审美痕迹推导 4 件事 — 思维模式 / 心路历程 / 来时路 / 未来路径。

### 4 块的推理强度不同（必须在 §0 声明）

| 块 | 性质 | 推理强度 |
|---|---|---|
| 思维模式 | 从反复出现的思考方式抽出 | **较强**（高频可观察） |
| 心路历程 | 从审美演变 + 触发事件推断内在变化 | 中（不可直接观察） |
| 来时路 | 从公开材料 + 偶像系谱推断审美形成史 | 中（部分依赖推断） |
| 未来路径 | 基于审美约束 + 当前判断外推 | **弱**（重点是"不会做什么"远比"会做什么"可信） |

### 产物：`portrait.md`

- §0 阅读须知（4 块推理强度声明）
- §1 思维模式（他怎么用审美做判断 — 包括思考工具 / 决策框架）
- §2 心路历程（审美如何演变 + 阶段划分 + 触发事件 + 演变总规律）
- §3 来时路（审美怎么长出来 — 教育 / 关键人物 / 偶像系谱 / 在地浸润 / 推断源）
- §4 未来路径（外推 + **重点：他不会做什么** + 关键分叉点 + 长期方向）
- §5 综合：一句话画像 + 5 条核心
- §6 缺口 + 后续 Phase 候选

### 关键设计：§4.2 "他不会做什么" > §4.1 "他会做什么"

"他不会做什么"由审美直接约束，**可证伪程度更高**。
"他会做什么"是基于趋势外推 — 信心标低。

**自检 bar**：
- 每条 claim 可追溯到痕迹 / 证据 ID
- §4.2 "不会做"清单 ≥ §4.1 "会做"清单
- 推理强度声明明确

## M-xxx 手动接力协议

遇到登录态 / 反爬 / 付费墙 / 私密内容时，向用户发任务卡：

```
🙋‍♂️ 请接力（M-xxx）
─────────────────────
要什么：[具体内容]
为什么我搞不定：[技术原因]
你的成本：约 X 分钟
怎么交回：
  方式 A：贴在对话里
  方式 B：保存为 .md 丢到 ~/analyst-skills/runs/<slug>/inbox/
我拿到后做：[下一步]
你可以否决：直接说"跳过"，我用替代源
```

### 常见 M-xxx 场景

由实战 dogfood 识别：

| 场景 | 原因 | 接力成本估计 |
|---|---|---|
| 微信公众号全量历史列表 | 无官方路径，第三方都不稳 | 8-12 分钟 |
| 知乎专栏（zhuanlan.zhihu.com）| 反爬 403（实测） | 5 分钟 |
| LinkedIn 完整履历 | 反爬严重 | 8 分钟 |
| 朋友圈 / 知识星球 | 登录态 + 付费墙 | 5-10 分钟 |
| 长视频 / 播客没字幕 | whisper 转写本地慢、API 付费 | 用户挑关键段 5-10 分钟 |
| 圈内传言 / 私下口碑 | 不在公开互联网 | 用户找熟人侧证 |

详细 platform 笔记见 [shared/sources-toolkit/](../../../analyst-skills/shared/sources-toolkit/)。

### 接力的失败模式（待迭代）

如果用户多次否决 / 没意愿接力，skill 应主动**降档**而不是硬撑（待 ADR 003 待跟进项跟进具体规则）。

## Phase 化的中间停止点

任一 phase 完成后可停下来 review。常见 review 点：

| 停止点 | 用户应该 review 什么 |
|---|---|
| Phase 0 完成 | 信源矩阵是否抓对主战场；M-xxx 候选你愿意做几个 |
| Phase 1 完成 | 是否达 bar；要不要补 |
| Phase 2A 完成 | 5 条审美陈述是否校准 |
| Phase 2B 完成 | 四画像是否过度推断 |

用户可在任一停止点 ✅/✏️/❌ 干预。
