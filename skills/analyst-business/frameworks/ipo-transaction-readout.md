# 交易层取证锚 + 从价钱倒推

交易层买方坐 IPO 申购方的椅子。本框架管"招股书里盯哪几处、怎么用"。

## 测谎仪优先级（散文可包装，数字难粉饰）

审计三表 > 风险因素章节 > 客户购买行为(Level B) > 外部对标 > 公司散文。背离时信前者。

## 三表测谎（master 指标）

| 测谎仪 | 软件/平台公司 | 裸算力转售/基建 | 背离信号 |
|---|---|---|---|
| **毛利率** | 60–80%+ | 20–40%（注意折旧口径） | 嘴上"平台"、毛利 25% = 穿软件外套的算力贩子 |
| **Capex/营收 · 折旧/营收** | 极低 | 折旧线吞利润 | "轻资产平台"却巨额 capex = 电力+地产生意 |
| **人员结构** | 工程师为主 | IDC 运维/销售/建设为主 | 80% 人头在运维 = 重资产本质 |
| **单客户集中度** | 分散 | 巨鲸客户（一家占大半营收） | "深度战略合作" = 危险集中度的伪装 |

## 交易层取证锚

| 锚点 | 卖方会怎么用 | 买方怎么读出本质 |
|---|---|---|
| **募资用途** | "投研发/平台" | 钱主要去买卡/建 IDC → 坐实重资产 + 预示持续融资=持续摊薄 |
| **估值倍数 vs comp** | 挑软件 comp 对标 | 摆到裸算力 comp（CoreWeave/Lambda）旁——它选哪类 comp 暴露在卖哪个故事 |
| **基石投资者** | "顶级机构背书" | 战略验证者（芯片厂/模型厂/主权基金）还是关系盘凑书？HK 基石常是锁仓关系钱，≠ 估值认可 |
| **上市章节（18C 等）** | "前沿科技" | 走 18C = 没法靠盈利上市 → 亏损是阶段性投资还是模式不成立 |
| **对赌/优先股/赎回权** | 不主动提 | 早期 sophisticated 买方谈的下行保护 = 他们当年觉得多险 |
| **老股转让/锁定期** | 不主动提 | 创始人/早期投资人借 IPO 套现离场 = cap table 里藏的卖方信号 |
| **风险因素章节** | 法律免责 | **被迫的认罪书**——当买方 checklist 逐条摘 |

## 操作纪律：从价钱倒推（不是顺着叙事读）

1. 发行价**隐含**了哪一组必须成立的假设（增长率、毛利上行、护城河持续、利用率）？
2. 逐条用去包装后的本质检验——**哪条撑不住，差额就在那。**
3. 给出"要相信什么、你才该按这个价申购" → 再判这些信念真不真。

（即 expectations investing / 反向 DCF：价钱是已知，倒推市场在为什么定价。）

## 认识论陷阱（铁律延伸）

IPO 阶段买方取证输入大半也来自卖方文件。解法：靠审计数字、读风险因素当真相、拿公司管不着的外部锚三角、缺口走 M-xxx。否则=用"买方视角"之名行"换一套卖方材料"之实。
