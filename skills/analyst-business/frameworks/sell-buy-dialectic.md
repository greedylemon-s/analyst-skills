# 卖方-买方双视角（analyst-business 招牌方法）

本框架是 `methodology/06-buy-side-sell-side-lens.md` 的**操作化**。引擎逻辑读那条，本文件管"具体怎么做一条 thread"。

## 一条 thread 的两侧手艺

### 卖方侧：steelman pitch 复原
不是抄它说了什么，是复原它**最强**版本 + 战略逻辑：
- 它讲什么故事？摆了哪些证据？想让你得出什么结论？
- **这套框法瞄准哪类估值倍数**？（这是关键——卖方所有框法都服务于估值）
- 承重墙是哪几句？哪句倒了整个 pitch 就倒？
- 质检线：**公司 CFO 看了会承认"这是对我们 pitch 的公允复述"**。做不到这条 = 你在打稻草人。

### 买方侧：抽丝剥茧（逐层、可核查、收敛）
每一层是一个**具体动作**，不是态度：

1. **claim** → 这条要成立，**必须为真的是什么**？
2. **拿什么验** → 翻哪张表 / 查哪个口径 / 比哪个 comp / 问哪个人
3. **证据怎么说** → 数字 / 风险因素 / 对标 / 客户行为（Level B）
4. **残余不确定** → 还有什么没验？落到未知清单 / M-xxx
5. **决策更新** → 这条让裁决朝买/不买移动多少

## 两栏并排，差额自己跳出来

把卖方 steelman 和买方剥茧并排放 → **背离处即本质**。
经典背离：公司在卖软件叙事，三表在说基建本质 → IPO 请你为基建生意付软件的价钱。这个差额就是投资决策本身。

## 三条护栏（来自 methodology 06）

1. 只对**承重 claim**（3–5 条）做完整剥茧；鸡毛蒜皮排两栏 = 注水。
2. 剥茧必须**收敛到裁决**（买/不买/什么价）；停在"有意思的线索" = 犹豫。
3. **price the gap，不 assume the lie**；证据若支持卖方，就承认卖方对。

## 用什么当测谎仪

散文可包装，**数字难粉饰**。优先级：审计三表 > 风险因素章节（法律强制认罪）> 客户购买行为 > 公司管不着的外部对标 > 公司散文宣称。
背离时信前者。
